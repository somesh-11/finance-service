# finance-service
Built a cloud-based Finance Service using AWS EC2 and S3. EC2 powers the backend and handles financial operations with scalable performance, while S3 securely stores reports, transaction data, and documents. Designed with a cloud-first architecture focused on reliability, scalability, and efficient data management.

## Features

* Responsive finance website UI
* Interactive frontend using JavaScript
* Backend form handling with PHP
* AWS EC2 deployment support
* AWS S3 integration for secure file storage
* Clean and scalable project structure

## Setup Instructions

1. Clone the repository

```bash
git clone <repository-link>
```

2. Move into the project folder

```bash
cd finance-website
```

3. Run the project on a local server (XAMPP/WAMP/LAMP)

4. Configure AWS credentials for S3 integration

5. Deploy the project on an AWS EC2 instance

## AWS Usage

* **EC2** is used for hosting the application and handling backend operations.
* **S3** is used for storing uploaded files, reports, and financial documents securely.
